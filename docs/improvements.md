# 5 улучшений для личного кабинета MOS.ru

Каждое улучшение сформулировано как гипотеза с ожидаемой метрикой (принцип из Лекции 1: "не делать задачи, а делать ставки").

## 1. Единая панель управления активными услугами (Дашборд)
- **Проблема:** Услуги разрознены, пользователю сложно отслеживать статусы разных обращений
- **Решение:** Главный экран с виджетами всех активных услуг и их текущих статусов
- **Ожидаемая метрика:** Снижение количества обращений в техподдержку со статусом "Где мое заявление?" на 20%

## 2. Умные уведомления о сроках (Smart Notifications)
- **Проблема:** Пользователи пропускают сроки оплаты или продления документов, получая штрафы
- **Решение:** Персонализированные push/email-уведомления за 3 дня до дедлайна с кнопкой быстрой оплаты/продления
- **Ожидаемая метрика:** Снижение просроченных платежей/документов на 30%
- - **Технические требования (по замечанию Backend-разработчика):** необходим источник данных для триггеров — таблица `user_deadlines` в БД с полями (user_id, service_type, deadline_date, status) и cron-задача для ежедневной проверки. Добавлено в бэклог как требование к API уведомлений.

## 3. Блок "Частые действия" с кастомизацией
- **Проблема:** Популярные услуги (например, передача показаний или оплата ЖКХ) скрыты глубоко в меню
- **Решение:** Закрепленный блок на главном экране, который пользователь может настроить под себя
- **Ожидаемая метрика:** Снижение времени выполнения типовых операций пользователем на 40%

## 4. Единая история всех обращений и документов
- **Проблема:** Нет централизованного архива, сложно найти старые справки или ответы
- **Решение:** Раздел "История" с фильтрами по дате, типу услуги и полнотекстовым поиском
- **Ожидаемая метрика:** Снижение запросов на повторную выдачу документов на 25%
- - **Технические требования (по замечанию Backend-разработчика):** необходимо учесть требования 152-ФЗ о сроках хранения персональных данных и механизме анонимизации после истечения срока. Добавлено требование к compliance в бэклог.

## 5. Чат-бот с ИИ для простых вопросов (FAQ)
- **Проблема:** Линия поддержки перегружена типовыми вопросами ("как получить справку", "график работы")
- **Решение:** Внедрение умного чат-бота, который отвечает на вопросы из базы знаний и может запустить простой сценарий
- **Ожидаемая метрика:** Снижение нагрузки на первую линию поддержки на 35%, время ответа < 1 минуты
