# Анализ бенчмарков личных кабинетов

Для формирования улучшений ЛК MOS.ru были проанализированы лучшие практики на рынке:

## 1. Яндекс ID (Паспорт)
- **Почему крутой:** Единый вход во все сервисы, понятная навигация, быстрый доступ к часто используемым функциям
- **Метрика:** Время выполнения основных действий пользователем < 2 минут

## 2. Госуслуги
- **Почему крутой:** Полная прозрачная история обращений, статус услуг в реальном времени, отсутствие необходимости визита в ведомство
- **Метрика:** Процент повторных обращений в поддержку по одному вопросу

## 3. Личный кабинет Т-Банка
- **Почему крутой:** Персонализация, предиктивная аналитика (система сама предлагает нужную услугу), мгновенная поддержка
- **Метрика:** Конверсия в использование рекомендованных сервисов, NPS

## 4. Личный кабинет Авито
- **Почему крутой:** Простой интерфейс для управления объявлениями, встроенная аналитика просмотров и спроса
- **Метрика:** Время размещения нового объявления, конверсия просмотра в контакт
