# Процесс работы над улучшениями: от идеи до запуска

Процесс выстроен по принципам продуктовой разработки (Discovery → Delivery):

## 1. Discovery (Исследование) — 1–2 недели
- Проведение 10–15 CustDev-интервью с пользователями ЛК MOS для валидации проблем
- Анализ текущих воронок и метрик продукта
- Формирование и приоритизация гипотез по фреймворку RICE

## 2. Прототипирование и дизайн — 1–2 недели
- Создание wireframes и кликабельных прототипов в Figma
- Быстрое юзабилити-тестирование прототипов на 5–7 пользователях
- Корректировка дизайна на основе фидбека

## 3. Разработка (Delivery) — 2–4 недели
- Декомпозиция задач на спринты (по 2 недели)
- Ежедневные стендапы и демо результатов команде
- Написание автотестов QA-инженерами параллельно с разработкой

## 4. Запуск и анализ (Launch & Learn) — 1–2 недели
- Постепенный rollout (канареечный релиз): 10% → 50% → 100% пользователей
- Мониторинг технических метрик (ошибки, время отклика) и продуктовых метрик (конверсия)
- Сбор качественной обратной связи и планирование следующей итерации
